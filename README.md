# Чеканка по полированному алюминию — внешняя версия (текстуры отдельными файлами)

## Структура

```
metal-page/
  index.html          ← страница (16 КБ, без встроенных картинок)
  embed.py            ← скрипт сборки одного файла metal.html
  textures/
    normal.png        ← Normal Map (ваша чеканка)
    aluminum.jpg      ← текстура алюминия
    hdri.jpg          ← HDRI для отражений
../metal.html         ← собранный один файл (встроенные текстуры)
```

## Как менять текстуры (главное)

Просто **перезапишите файлы в `textures/` своими, с теми же именами**:

- `textures/normal.png` — новая Normal Map
- `textures/aluminum.jpg` — новый алюминий
- `textures/hdri.jpg` — новый HDRI (equirect 2:1)

И обновите страницу в браузере (Ctrl+R). Больше ничего делать не нужно.

> Имена файлов менять нельзя — в `index.html` пути прописаны именно такие:
> `NORMAL_DATA="textures/normal.png"`, `ALU_DATA="textures/aluminum.jpg"`, `HDRI_DATA="textures/hdri.jpg"`.
> Если хотите другие имена — поправьте эти три строки в `index.html`.

## Как запустить

Через сервер (двойной клик по файлу не сработает — браузер блокирует текстуры по CORS):

```bash
cd metal-page
python3 -m http.server 8000
# открыть http://localhost:8000
```

В Arena используйте живой предпросмотр (сервер на порту 8000 уже запущен).
Предпросмотр файла в просмотрщике Arena текстуры не подгрузит — это ограничение песочницы.

## Если нужен снова один файл

```bash
cd metal-page
python3 embed.py
# получится ../metal.html — один файл со встроенными текстурами,
# открывается двойным кликом без сервера
```

Normal Map при этом автоматически сжимается до 1800px JPEG, чтобы файл не раздувался до 12 МБ.
